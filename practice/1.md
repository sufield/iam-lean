In Lean 4, `#eval 1 + 1` is represented as a nested tree of **`Expr.app`** (application) nodes. The operator `+` desugars to the constant **`HAdd.hAdd`**, which takes six arguments (four implicit/instance and two explicit).

The abstract syntax tree (AST) looks like this:

```text
               Expr.app (Application)
              /        \
          Expr.app      Expr.lit (natVal 1)  <-- Right Operand
         /        \
     Expr.app      Expr.lit (natVal 1)       <-- Left Operand
    /        \
Expr.app      [Instance: HAdd Nat Nat Nat]    <-- Typeclass
  ...          /
Expr.const `HAdd.hAdd [level_param]          <-- The function
```

*   **`Expr.const`**: The fundamental function `HAdd.hAdd`.
*   **`Expr.lit`**: The numeric values `1` and `1` (represented internally as `.natVal 1`).
*   **`Expr.app`**: Every branch in the tree. Because Lean uses currying, a function with multiple arguments is a series of nested applications.
*   **Implicit Arguments**: Even though you only typed `1 + 1`, the tree includes the types (`Nat`) and the typeclass instance that defines how to add them.
