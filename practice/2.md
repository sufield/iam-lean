For the expression `"Hello" ++ "!"`, the `++` operator desugars to **`HAppend.hAppend`**. Just like addition, it is represented as a series of nested **`Expr.app`** nodes involving implicit type information and a typeclass instance.

```text
                Expr.app (Application)
               /        \
           Expr.app      Expr.lit (strVal "!")      <-- Right Operand
          /        \
      Expr.app      Expr.lit (strVal "Hello")      <-- Left Operand
     /        \
 Expr.app      [Instance: HAppend String String String]
   ...          /
Expr.const `HAppend.hAppend [level_params]          <-- The function
```

### Differences from `1 + 1`:

*   **`Expr.const`**: Uses `HAppend.hAppend` instead of `HAdd.hAdd`.
*   **`Expr.lit`**: Uses **`.strVal`** (string literals) instead of `.natVal`.
*   **Implicit Arguments**: The tree includes three type arguments (all `String`) and the specific `HAppend` instance that handles string concatenation.
*   **Currying**: Lean applies arguments one by one, so `"Hello" ++ "!"` is internally `(((HAppend.hAppend String String String) instance) "Hello") "!"`.
