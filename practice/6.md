There is an AST, but we need to distinguish between the **Command** and the **Expression**.

### 1. The Expression (`Expr`)

The argument `"Hello World"` is the simplest possible expression tree. It doesn't have applications or functions; it is a single leaf node.

```text
Expr.lit (strVal "Hello World")
```

### 2. The Command (`Syntax`)

The `#check` part is not an `Expr`. In Lean, `#check` is a **Command**. Commands exist in the **Syntax** tree (the raw structure of the code) but are not processed by the Logic Kernel.

If you look at the **Syntax AST** (what the parser sees before it becomes an expression), it looks like this:

```text
Syntax (node `Lean.Parser.Command.check)
├── Syntax (atom "#check")
└── Syntax (node `Lean.Parser.Term.str)
    └── Syntax (atom "\"Hello World\"")
```

*   **`Expr`** is for **Logic**: It represents "What does this mean?" (A string literal).
*   **`Syntax`** is for **Tooling**: It represents "What did the user type?" (The `#check` command).

When you run `#check "Hello World"`, Lean takes the `Syntax`, extracts the `Expr` from it, determines the type of that `Expr` (`String`), and then displays that type in your Infoview.
