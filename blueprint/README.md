# Blueprint — Local Build

## Prerequisites

```bash
# mdBook
cargo install mdbook

# Graphviz (for dependency graph)
sudo apt install graphviz

# Python 3.10+
```

## Build

All commands run from the repo root (`iam-explainer/`):

```bash
# 1. Extract declarations from Lean source
python3 blueprint/scripts/extract.py

# 2. Build the site
cd blueprint/book && mdbook build

# 3. Open the site
open blueprint/site/index.html
# — or serve it locally:
mdbook serve --open
# Opens http://localhost:3000
```

## What it generates

- **Theorem Catalog** (`catalog.md`) — flat table of all theorems/lemmas with status badges
- **Dependency Graph** (`graph.md`) — Graphviz SVG of declaration dependencies
- **Module Pages** (`modules/*.md`) — one page per `.lean` file with signatures and docstrings

All content under `book/src/` is generated by `scripts/extract.py` from the Lean source. Never edit the generated files.
