# Blueprint — Local Build

## Prerequisites

```bash
# mdBook
cargo install mdbook
# — or download from https://github.com/rust-lang/mdBook/releases

# Python 3.10+
```

## Build

From the repo root:

```bash
# 1. Extract declarations from Lean source
python3 blueprint/scripts/extract.py

# 2. Build the site
cd blueprint/book && mdbook build

# 3. Serve locally
mdbook serve --open
# Opens http://localhost:3000
```

## What it generates

- **Theorem Catalog** (`catalog.md`) — flat table of all theorems/lemmas with status badges, sortable
- **Dependency Graph** (`graph.md`) — Mermaid graph of declaration dependencies
- **Module Pages** (`modules/*.md`) — one page per `.lean` file with signatures and docstrings

All content is generated by `scripts/extract.py` from the Lean source. Never edit the generated files.
